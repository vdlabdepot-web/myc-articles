# myc — articles ready to publish

Article drafts about [myc](https://github.com/aistastudio/myc), a local task-and-memory layer for coding agents, in the formats the platforms expect.

| Platform | File | How it publishes |
|---|---|---|
| Zenn (JP) | `articles/*.md` | connect this repo in Zenn → Deploy settings → the article appears |
| Qiita (JP) | `public/qiita/*.md` | `npx qiita publish --all` with a Qiita token, or paste |
| 掘金 / 知乎 / CSDN (CN) | `zh-juejin-zhihu-csdn.md` | paste |
| dev.to / Hashnode (EN) | `en-devto-hashnode.md` | paste, or dev.to API |

Every number in the texts comes from the myc repository's `site/measurements.json`.
